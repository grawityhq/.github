## What we're building

Coaching institutes still run on spreadsheets, WhatsApp groups, and paper
registers. Grawity replaces that with one platform — admissions to attendance to
fees to results — built multi-tenant from day one so every institute gets its own
isolated workspace without its own deployment.

## The platform

| Product | What it does |
| --- | --- |
| **GIMS** | Core institute management — students, batches, attendance, fees, exams, reporting. |
| **Grawity ID** | Single sign-on and role-based access across every Grawity product. |
| **Grawity Classroom** | Teaching layer — assignments, study material, and day-to-day class workflow. |
| **Grawity Web** | Public site and marketing surface for the platform. |

> Source repositories are private while the platform is in active development.
> For a demo or pilot access, reach out at [info@grawity.in](mailto:info@grawity.in).

## Engineering

**TypeScript** end to end · **React** on the front end · **Node.js / Express** on the
back end · **MongoDB** for storage.

Principles we hold to: strict tenant isolation, typed contracts between services,
audit trails on anything touching money or marks, and no feature that a
non-technical institute admin can't use on the first try.
